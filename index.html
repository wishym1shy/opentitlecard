Cards
Cards share one style (font, colors, box) unless you tick own style for one (◆). Text, per-word color, italic and line nudges always belong to each card. Canvas size is shared by the whole export. Cards are not kept in the browser: use Save batch to file to keep a batch, and Open batch file… to load it again.
Text
Select a word (or just put the caret in it) then click a color. Click a word in the preview to select it. Paste or type an emoji and it becomes an empty slot.
Alt+1–9 palette · Ctrl+I italic
Line nudge (text inside fill)
Moves each line's text (and its emoji slot) without moving the box. Units are px at 1080p; sliders rest at 0 in the middle (right = +, and +Y is down). Drag the X/Y labels to scrub, type a value, or use the arrow keys (Shift = 10). Double-click to reset one axis, or Alt-drag text in the preview.
Font & type
Off = only your own line breaks. Otherwise long lines wrap at spaces to fit. Line nudges stay with line numbers.
